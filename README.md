# Pulse

Музыкальный плеер для Windows: Spotify, SoundCloud и YouTube в одном приложении.
Общий поиск, очередь, лайки и плейлисты со всех площадок, тексты песен с синхронизацией.

## Установка

Скачайте `Pulse-Setup-<версия>.exe` из раздела [Releases](https://github.com/enum000/pulse-releases/releases/latest) и запустите.
Windows может показать предупреждение SmartScreen: «Подробнее» → «Выполнить в любом случае».

## Обновления

Pulse сам проверяет обновления, скачивает их в фоне и ставит при перезапуске.
Проверить вручную можно в Настройки → Pulse.

## Удаление

«Параметры Windows» → «Приложения» → Pulse → «Удалить», или Настройки → Pulse → «Удалить Pulse».
При удалении Pulse спросит, стереть ли также ваши данные (лайки, плейлисты, вход в Spotify).
